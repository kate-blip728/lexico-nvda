Léxico para NVDA 0.5.0

Versión inicial para NVDA 2026.2. No se ha verificado todavía la interfaz dentro de NVDA ni una traducción real con Gemini. El cifrado nativo de la clave queda pendiente de verificar dentro de NVDA: el entorno aislado de desarrollo no accede al perfil de Windows necesario. Si no puede cifrar, el complemento avisa y no guarda la clave en texto plano.

Uso

Abre NVDA → Herramientas → Léxico: diccionario y traducción. Escribe una palabra y pulsa Buscar en el DLE, o pulsa Palabra del día. Los resultados aparecen en un campo de texto de solo lectura: usa las flechas para leerlos y Copiar resultado para copiarlos.

Para traducir, abre Opciones, introduce tu clave de API de Gemini, el idioma de destino y un modelo disponible en tu cuenta. El modelo inicial es gemini-3.5-flash-lite. Escribe o pega el texto y pulsa Traducir. La aplicación Gemini no sustituye una clave de API. Puedes obtenerla en Google AI Studio.

Tab y Mayús+Tab recorren los controles; Escape cierra la ventana. Los comandos aparecen en Preferencias → Gestos de entrada → Léxico. El gesto NVDA+Control+Mayús+D consulta la definición del portapapeles; puedes cambiarlo en Gestos de entrada. Los demás comandos no tienen atajos globales asignados inicialmente.

Preferencias

Idioma, modelo y clave se guardan inmediatamente al aceptar Opciones, en la configuración de esta copia de NVDA. La clave se cifra con DPAPI para tu usuario de Windows. Al moverla a otro equipo o usuario tendrás que introducirla de nuevo. El historial guarda textos y resultados localmente en la configuración de NVDA. En Opciones puedes indicar el máximo de entradas: 100 por defecto, entre 0 y 10000; 0 desactiva y vacía el historial. Puedes recuperar, copiar, eliminar y vaciar las consultas sin enviarlas otra vez a Gemini.

Servicios

Las palabras se consultan mediante RAE API, intermediario independiente no oficial que devuelve contenido del DLE. No es una API oficial de la RAE. La conexión directa al DLE fue rechazada con HTTP 403 durante las pruebas. El servicio puede aplicar límites y sus datos pueden no coincidir con la última actualización. Se muestran sinónimos y antónimos por acepción cuando el intermediario los devuelve.

Al pulsar Traducir, se envían el texto y el idioma a Google Gemini. Tu cuenta puede tener cuotas o costes. La clave solo se envía a Google. No hay consultas automáticas al arrancar NVDA y el complemento no se activa en modo seguro.

Cuadros combinados y creación de claves

Idioma y modelo son cuadros combinados editables. Usa las flechas para elegir o escribe otra opción. Se conservan las preferencias anteriores. El botón Usar modelo recomendado selecciona Gemini 3.5 Flash-Lite; acepta Opciones para guardar el cambio. Es el modelo predeterminado en instalaciones nuevas, elegido por rapidez y menor coste para traducciones de texto.

Opciones incluye botones para crear la clave de Gemini en Google AI Studio y abrir las credenciales de Google Cloud. Para este complemento crea una clave de Gemini en AI Studio, vinculada a tu proyecto de Cloud. El complemento utiliza Gemini Developer API.

Cómo se escribe

Escribe una sola palabra en Palabra o expresión y pulsa Comprobar escritura. Windows muestra posibles sugerencias en Resultado. No se usa Gemini y no se determina si la palabra es adecuada en cada contexto.

Corregir con Windows

Escribe o pega texto y pulsa Corregir con Windows. Pulsa Revisar ortografía, elige una aparición, selecciona o escribe un reemplazo y pulsa Aplicar a esta aparición. Un reemplazo vacío elimina esa aparición. Usa Usar texto revisado para devolver el texto a Léxico o Cancelar para descartar los cambios. No se modifica el documento de otra aplicación ni se copia automáticamente al portapapeles.

Esta función utiliza Windows Spell Checking API sin peticiones de red ni Gemini. Revisa ortografía, no toda la gramática. El idioma del corrector se guarda en Opciones y es independiente del idioma de traducción; Windows necesita tener instalado ese diccionario.

Preguntar a Gemini

El botón abre un campo para escribir una duda gramatical u otra consulta. Al aceptar se envía esa pregunta a Gemini con el modelo y la clave configurados; la respuesta en español aparece en Resultado. No se envía automáticamente el texto de corrección.

Estado de la prueba de Windows

El corrector nativo recibió acceso denegado (0x80070005) en el entorno de desarrollo. Su funcionamiento dentro de NVDA queda pendiente de comprobar, junto con la interfaz, el cifrado nativo de la clave y una consulta real a Gemini.

Traducir el portapapeles

El botón Traducir portapapeles y el gesto correspondiente inician directamente la traducción con el idioma y modelo configurados. No tienes que pulsar Traducir después. El original aparece en el campo de entrada y la respuesta de Gemini en Resultado. Para pegar sin traducir, usa Control+V. Si hay una consulta en curso, espera a que termine. La comprobación de este cambio se ha realizado con Gemini simulado; la prueba real dentro de NVDA sigue pendiente.

Idioma de destino y texto sin cambios

Para traducir un texto inglés a español, elige español como Idioma de destino y acepta Opciones. Si Gemini devuelve el original, se hace un solo reintento, que cuenta como una petición adicional. Si vuelve a devolverlo sin cambios, se muestra un aviso con el idioma de destino. La versión aparece en el título de la ventana para comprobar qué actualización está activa.

Actualizaciones e historial

Buscar actualizaciones consulta update.json en el repositorio público de GitHub. Si hay una versión superior, permite descargar y abrir el instalador tras verificar su SHA-256 y manifiesto. NVDA solicita la instalación y el reinicio. No se instala automáticamente. Historial permite leer y recuperar el original y su resultado, copiarlo, eliminar entradas o vaciarlo. Las consultas fallidas no se guardan. Las claves no se guardan en el historial; los textos y resultados se guardan localmente sin cifrado.

DPD dentro de Léxico

Escribe una palabra o expresión en Palabra o expresión y pulsa Consultar DPD. El artículo oficial del Diccionario panhispánico de dudas aparece en Resultado: léelo con las flechas o cópialo. Se conserva en el historial. Esta consulta se envía directamente a www.rae.es, sin Gemini y sin abrir un navegador. Las remisiones de la RAE pueden devolver otra entrada, cuya dirección se indica. Las referencias internas se muestran como texto; escribe el nombre de la entrada para consultarla. Si no hay entrada o se bloquea el acceso, se muestra un aviso.

Definición del portapapeles

Copia una palabra o expresión y pulsa NVDA+Control+Mayús+D. Léxico se abre si hace falta y consulta su definición en el DLE. También existe el botón Definición del portapapeles. El texto de traducción y el portapapeles no se modifican. Se admite una sola línea de hasta 150 caracteres. Puedes cambiar el atajo en NVDA → Preferencias → Gestos de entrada → Léxico.
